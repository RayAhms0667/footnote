# Footnote

A daily retro history trivia game. Seven questions a day (2 easy, 2 medium, 3 hard). Obvious answers score a little, obscure ones score a lot, and your points upgrade a pixel tank all the way to an orbital rocket.

**Play:** https://rayahms0667.github.io/footnote/

- One round per day; everyone gets the same questions, reset at midnight local time
- 110 question categories with answers in five rarity tiers
- Original chiptune soundtrack generated in the browser
- Player accounts or guest play, saved in your browser

The whole game is a single `index.html` with no build step.
